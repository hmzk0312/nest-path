# NestPath

> Build your nest. Plan your path.

NestPath is a retirement planning simulator for long-term, diversified investing.

現在の資産と将来の収入・支出・運用条件をもとに、退職年齢や積立・売却計画が異なる二つのプランを比較し、設定した年齢まで資産が持つかを確認するための個人向けアプリケーションです。

## Goal

NestPathのMVPは、次の問いに答えられることを目標とします。

> 現在の資産と今後の収支を前提に、この退職計画で、設定した年齢まで生活資金が持つか。

アプリが最適な退職時期を自動的に決めるのではなく、利用者が条件の異なる二つのプランを比較し、自分で判断するための材料を提供します。

## MVP Scope

### 1. 基本条件

以下を設定できます。

- シミュレーション開始年月
- 生年月
- 退職年月
- シミュレーション終了年齢
- 年間インフレ率

シミュレーションは月単位で行います。
現在年齢は生年月と対象年月から算出します。退職年月は最後の勤務月とし、終了年齢に達する月の月末まで計算します。

### 2. 保有資産

口座や商品を個別に登録できます。

各資産には以下を設定します。

- 名称
- 資産区分
- 現在残高
- 投資元本または取得価格
- 年間想定利回り
- 引出可能時期
- DC・iDeCoの概算受取税率（該当する場合）

MVPで扱う資産区分は以下です。

- 現金・預金
- 課税口座の株式・投資信託
- NISAの株式・投資信託
- DC・iDeCo
- 自社株・持株会

過去の購入・売却履歴は登録せず、現在残高と取得価格をシミュレーションの出発点とします。

現金・預金のうち一つを生活資金口座として指定し、収入、生活費、売却代金および積立資金の入出金を反映します。その他の現金・預金から生活資金口座への資金移動は自動では行いません。

### 3. 収入

以下の定期収入を設定できます。

- 退職前の給与
- 公的年金
- 企業年金・個人年金
- 退職後の労働収入

各収入には、開始年月、終了年月、額面金額、概算税率を設定します。税引後収入は、入力した概算税率を用いて算出します。

額面金額はシミュレーション開始時点の現在価値で入力し、設定したインフレ率を反映してから概算税率を適用します。将来開始する収入も、シミュレーション開始月から開始年月までインフレ調整します。

給与と賞与は、MVPでは月額へ平均化して入力します。

### 4. 支出

以下の支出を設定できます。

- 退職前の毎月の基本生活費
- 退職後の毎月の基本生活費

生活費はシミュレーション開始時点の現在価値で入力し、設定したインフレ率をシミュレーション開始月から反映します。退職後生活費も、退職年月の翌月までインフレ調整した金額から支出を開始します。

### 5. 積立計画

将来の積立について、以下を設定できます。

- 積立先の資産
- 毎月の積立額
- 開始年月
- 終了年月

### 6. 売却計画

将来の売却について、以下を設定できます。

- 売却元の資産
- 売却年月
- 売却金額

生活用の現金が不足しても、資産は自動的に売却しません。

引出可能時期より前の売却予定は実行せず、翌月以降へ自動延期しません。売却予定額が資産残高を超える場合は、資産残高を上限として売却し、不足額を警告します。

課税口座と自社株・持株会については、取得原価を売却割合で按分し、プラスの売却益に共通の概算税率を適用します。NISAの売却益には課税しません。DC・iDeCoの取崩しには、商品ごとの概算受取税率を適用します。

### 7. 資産推移の計算

シミュレーション開始年月から終了年齢まで、以下を月単位で反映します。

- 税引後収入
- 基本生活費
- インフレ
- 毎月の積立
- 指定した売却
- 資産ごとの運用利回り
- 資産の引出可能時期
- 売却益に対する概算税額

運用結果は、入力した一定の想定利回りに基づく単一の見通しです。市場変動を確率的には計算しません。

年間インフレ率と年間想定利回りは、複利で月次換算します。当月の入金は翌月から運用対象とし、当月に資産から出た金額は当月の運用対象から除外します。そのため、当月の積立額と売却額には当月の運用損益を付けません。

### 8. 二つのプランの比較

同じ現在資産を出発点として二つのプランを保存し、以下の条件を変更して比較できます。

- 退職年齢
- 毎月の積立額
- 資産の売却時期
- 資産の売却金額

比較結果では、少なくとも以下を確認できます。

- 月ごとの総資産
- 月ごとの税引後使用可能額
- 月ごとの現金残高
- 終了年齢時点の資産
- 商品ごとの残高推移
- 二つのプランの差

### 9. 現金不足の警告

生活用の現金が不足した場合は、資産を自動売却せずに警告を表示し、シミュレーションを継続します。

生活資金口座のマイナス残高は0円に補正せず、累積して賄えなかった生活資金として翌月へ引き継ぎます。後の収入や予定売却で解消した場合も、現金不足が発生した履歴は残します。

現金不足と資産枯渇は別に判定します。生活資金口座が0円未満の場合は現金不足、税引後使用可能額が0円以下の場合は資産枯渇とします。一度でも資産枯渇した計画は、後に回復しても「終了年齢まで資産を維持できた」とは判定しません。

警告では、少なくとも以下を確認できます。

- 最初に現金不足が発生した年月
- 不足額
- その時点の総資産
- その時点で売却可能な資産

### 10. 保存

以下を保存し、アプリを閉じた後も再度開くことができます。

- 現在の保有資産
- 二つのプラン
- 各プランの入力条件

## Out of Scope for MVP

以下は将来的な候補ですが、MVPには含めません。

- 過去の購入・売却履歴
- 毎月の実績登録
- 計画と実績の比較
- 日本の税制による税額の自動計算
- 住民税の年度差
- 所得控除や社会保険料の詳細計算
- 退職金の詳細な税計算
- DC・iDeCo受取時の詳細な税計算
- 旅行や住宅などの一時的な支出
- 一定期間だけ続く支出
- 配当・分配金
- 三つ以上のプランの同時比較
- 退職可能年齢の自動探索
- 現金不足時の自動売却
- 確率的な運用シミュレーション
- 複数ユーザー、認証、共有
- 月内の日付による日割り計算
- 課税口座の商品間・月間・年度内の損益通算
- 売却損の繰越控除
- 売却できなかった予定の自動延期
- 現金不足時の積立額の自動調整

## Acceptance Criteria

MVPは、以下の条件をすべて満たしたときに完成とします。

- [ ] 生年月、シミュレーション開始年月、退職年月、終了年齢を設定できる
- [ ] 生年月と対象年月から年齢を月単位で算出できる
- [ ] 複数の口座・商品を個別に登録できる
- [ ] 各資産に、名称、区分、現在残高、取得価格、想定利回り、引出可能時期を設定できる
- [ ] 現金・預金のうち一つを生活資金口座として指定できる
- [ ] 給与、年金、退職後の労働収入および基本生活費を、シミュレーション開始時点の現在価値として入力できる
- [ ] 収入と基本生活費へ、シミュレーション開始月からインフレを反映できる
- [ ] 年間インフレ率と年間想定利回りを複利で月次換算できる
- [ ] 当月の積立額と売却額を、当月の運用損益の対象外にできる
- [ ] DC・iDeCoに概算受取税率を設定できる
- [ ] 給与、年金、退職後の労働収入について、期間、額面金額、概算税率を設定できる
- [ ] 退職前後の基本生活費とインフレ率を設定できる
- [ ] 積立先、積立額、開始年月、終了年月を設定できる
- [ ] 売却元、売却年月、売却金額を設定できる
- [ ] 売却・取崩しの税引後受取額を、同じ月の生活費と積立に使用できる
- [ ] 引出可能時期前の売却予定を実行せず、警告を表示して計算を継続できる
- [ ] 売却予定額が資産残高を超える場合、残高まで売却して不足額を警告できる
- [ ] 一部売却時に取得原価を売却割合で按分し、残存取得原価を更新できる
- [ ] 入力条件に基づき、終了年齢までの資産推移を月単位で計算できる
- [ ] 課税口座と自社株・持株会のプラスの売却益へ共通の概算税率を適用し、NISAの売却益を非課税として扱える
- [ ] DC・iDeCoの取崩しへ、商品ごとの概算受取税率を適用できる
- [ ] 引出可能前の資産を総資産に含め、税引後使用可能額には含めない
- [ ] 同じ現在資産から始まる二つのプランを保存できる
- [ ] 二つのプランで、退職年齢、積立額、売却時期、売却金額を変更できる
- [ ] 二つのプランの総資産、税引後使用可能額、現金残高を比較できる
- [ ] 現金不足が発生した場合、自動売却せずに警告を表示できる
- [ ] 現金不足後もシミュレーションを継続できる
- [ ] 生活資金口座のマイナス残高を0円に補正せず、翌月へ引き継げる
- [ ] 現金不足と資産枯渇を、それぞれ現金残高と税引後使用可能額から別々に判定できる
- [ ] 引出可能な資産を仮想換金し、概算税を差し引いた税引後使用可能額を月ごとに計算できる
- [ ] 現金不足または資産枯渇の最初の発生月と、その後の回復を記録できる
- [ ] 一度でも資産枯渇した計画を、終了年齢まで資産を維持できなかったと判定できる
- [ ] 入力内容を変更して再計算できる
- [ ] アプリを閉じた後も、保存した資産とプランを再度開ける

## Data and Privacy

このリポジトリはPublicです。

- 実際の資産額、収入、年金見込額、取得価格などの個人データはコミットしません
- サンプルとテストには架空のデータを使用します
- 認証情報や秘密情報はコミットしません
- 個人データの保存先はGitの管理対象外にします

## Disclaimer

NestPathは個人の資産形成・退職計画を検討するためのシミュレーターです。投資、税務、法律その他の専門的な助言を提供するものではありません。計算結果は入力した仮定に基づく概算であり、将来の成果を保証しません。
