# NestPath

> Build your nest. Plan your path.

NestPath is a retirement planning simulator for long-term, diversified investing.

現在の資産と将来の収入・支出・運用条件をもとに、退職年齢や積立・売却計画が異なる二つのプランを比較し、設定した年齢まで資産が持つかを確認するための個人向けアプリケーションです。

## Status

MVP planning

現在はMVPの要求を定義した段階です。アーキテクチャ、技術構成、内部データモデルはまだ決定していません。

## Goal

NestPathのMVPは、次の問いに答えられることを目標とします。

> 現在の資産と今後の収支を前提に、この退職計画で、設定した年齢まで生活資金が持つか。

アプリが最適な退職時期を自動的に決めるのではなく、利用者が条件の異なる二つのプランを比較し、自分で判断するための材料を提供します。

## MVP Scope

### 1. 基本条件

以下を設定できます。

- シミュレーション開始年月
- 生年月または現在年齢
- 退職年月
- シミュレーション終了年齢
- 年間インフレ率

シミュレーションは月単位で行います。

### 2. 保有資産

口座や商品を個別に登録できます。

各資産には以下を設定します。

- 名称
- 資産区分
- 現在残高
- 投資元本または取得価格
- 年間想定利回り
- 引出可能時期

MVPで扱う資産区分は以下です。

- 現金・預金
- 課税口座の株式・投資信託
- NISAの株式・投資信託
- DC・iDeCo
- 自社株・持株会

過去の購入・売却履歴は登録せず、現在残高と取得価格をシミュレーションの出発点とします。

### 3. 収入

以下の定期収入を設定できます。

- 退職前の給与
- 公的年金
- 企業年金・個人年金
- 退職後の労働収入

各収入には、開始年月、終了年月、額面金額、概算税率を設定します。税引後収入は、入力した概算税率を用いて算出します。

給与と賞与は、MVPでは月額へ平均化して入力します。

### 4. 支出

以下の支出を設定できます。

- 退職前の毎月の基本生活費
- 退職後の毎月の基本生活費

生活費には、設定したインフレ率を反映します。

### 5. 積立計画

将来の積立について、以下を設定できます。

- 積立先の資産
- 毎月の積立額
- 開始年月
- 終了年月

### 6. 売却計画

将来の売却について、以下を設定できます。

- 売却元の資産
- 売却年月
- 売却金額

生活用の現金が不足しても、資産は自動的に売却しません。

課税口座については、取得価格と設定した概算税率をもとに、売却益に対する税金を概算します。NISAの売却益には課税しません。

### 7. 資産推移の計算

シミュレーション開始年月から終了年齢まで、以下を月単位で反映します。

- 税引後収入
- 基本生活費
- インフレ
- 毎月の積立
- 指定した売却
- 資産ごとの運用利回り
- 資産の引出可能時期
- 売却益に対する概算税額

運用結果は、入力した一定の想定利回りに基づく単一の見通しです。市場変動を確率的には計算しません。

### 8. 二つのプランの比較

同じ現在資産を出発点として二つのプランを保存し、以下の条件を変更して比較できます。

- 退職年齢
- 毎月の積立額
- 資産の売却時期
- 資産の売却金額

比較結果では、少なくとも以下を確認できます。

- 月ごとの総資産
- 月ごとの税引後使用可能額
- 月ごとの現金残高
- 終了年齢時点の資産
- 商品ごとの残高推移
- 二つのプランの差

### 9. 現金不足の警告

生活用の現金が不足した場合は、資産を自動売却せずに警告を表示し、シミュレーションを継続します。

警告では、少なくとも以下を確認できます。

- 最初に現金不足が発生した年月
- 不足額
- その時点の総資産
- その時点で売却可能な資産

### 10. 保存

以下を保存し、アプリを閉じた後も再度開くことができます。

- 現在の保有資産
- 二つのプラン
- 各プランの入力条件

## Out of Scope for MVP

以下は将来的な候補ですが、MVPには含めません。

- 過去の購入・売却履歴
- 毎月の実績登録
- 計画と実績の比較
- 日本の税制による税額の自動計算
- 住民税の年度差
- 所得控除や社会保険料の詳細計算
- 退職金の詳細な税計算
- DC・iDeCo受取時の詳細な税計算
- 旅行や住宅などの一時的な支出
- 一定期間だけ続く支出
- 配当・分配金
- 三つ以上のプランの同時比較
- 退職可能年齢の自動探索
- 現金不足時の自動売却
- 確率的な運用シミュレーション
- 複数ユーザー、認証、共有

## Acceptance Criteria

MVPは、以下の条件をすべて満たしたときに完成とします。

- [ ] 複数の口座・商品を個別に登録できる
- [ ] 各資産に、名称、区分、現在残高、取得価格、想定利回り、引出可能時期を設定できる
- [ ] 給与、年金、退職後の労働収入について、期間、額面金額、概算税率を設定できる
- [ ] 退職前後の基本生活費とインフレ率を設定できる
- [ ] 積立先、積立額、開始年月、終了年月を設定できる
- [ ] 売却元、売却年月、売却金額を設定できる
- [ ] 入力条件に基づき、終了年齢までの資産推移を月単位で計算できる
- [ ] 課税口座とNISAについて、売却益への課税有無を区別できる
- [ ] 引出可能前の資産を総資産に含め、税引後使用可能額には含めない
- [ ] 同じ現在資産から始まる二つのプランを保存できる
- [ ] 二つのプランで、退職年齢、積立額、売却時期、売却金額を変更できる
- [ ] 二つのプランの総資産、税引後使用可能額、現金残高を比較できる
- [ ] 現金不足が発生した場合、自動売却せずに警告を表示できる
- [ ] 現金不足後もシミュレーションを継続できる
- [ ] 入力内容を変更して再計算できる
- [ ] アプリを閉じた後も、保存した資産とプランを再度開ける

## Data and Privacy

このリポジトリはPublicです。

- 実際の資産額、収入、年金見込額、取得価格などの個人データはコミットしません
- サンプルとテストには架空のデータを使用します
- 認証情報や秘密情報はコミットしません
- 個人データの保存先はGitの管理対象外にします

## Disclaimer

NestPathは個人の資産形成・退職計画を検討するためのシミュレーターです。投資、税務、法律その他の専門的な助言を提供するものではありません。計算結果は入力した仮定に基づく概算であり、将来の成果を保証しません。
