# NestPath

> Build your nest. Plan your path.

NestPath is a retirement planning simulator for long-term, diversified investing.

現在の資産と将来の収入・支出・運用条件をもとに、一つの退職計画で設定した年齢まで資産が持つかを確認するための個人向けアプリケーションです。

## Goal

NestPathのMVPは、次の問いに答えられることを目標とします。

> 現在の資産と今後の収支を前提に、この退職計画で、設定した年齢まで生活資金が持つか。

アプリが最適な退職時期を自動的に決めるのではなく、利用者が一つのプランを計算し、入力条件を変更して再計算することで、自分で判断するための材料を提供します。

## MVP Scope

### 1. 基本条件

以下を設定できます。

- シミュレーション開始年月
- 生年月
- 退職年月
- シミュレーション終了年齢
- 年間インフレ率

シミュレーションは月単位で行います。
現在年齢は生年月と対象年月から算出します。退職年月は最後の勤務月とし、終了年齢に達する月の月末まで計算します。

### 2. 保有資産

一つの生活資金口座と、一つ以上の運用資産を登録できます。

MVPで扱う資産区分は以下です。

- 現金・預金
- 運用資産

各資産には以下を設定します。

- 名称
- 資産区分
- 現在残高
- 年間想定利回り（運用資産）

現金・預金の一つを生活資金口座として指定し、収入、生活費、売却代金および積立資金の入出金を反映します。

### 3. 収入

退職前と退職後の定期収入を設定できます。

収入額はシミュレーション開始時点の現在価値で入力し、設定したインフレ率を反映します。MVPでは収入税を計算しません。

### 4. 支出

以下の支出を設定できます。

- 退職前の毎月の基本生活費
- 退職後の毎月の基本生活費

生活費はシミュレーション開始時点の現在価値で入力し、設定したインフレ率をシミュレーション開始月から反映します。退職後生活費は、退職年月の翌月から支出します。

### 5. 積立計画

将来の積立について、以下を設定できます。

- 積立先の運用資産
- 毎月の積立額
- 開始年月
- 終了年月

### 6. 売却計画

将来の売却について、以下を設定できます。

- 売却元の運用資産
- 売却年月
- 売却予定額

生活資金口座が不足しても、運用資産は自動的に売却しません。

売却予定額が売却時点の資産残高を超える場合は、資産残高を上限として売却します。実行できなかった売却予定は、翌月以降へ自動延期しません。MVPでは売却益と税金を計算せず、実売却額と同額を生活資金口座へ入金します。

### 7. 資産推移の計算

シミュレーション開始年月から終了年齢まで、以下を月単位で反映します。

- 退職前後の定期収入
- 退職前後の基本生活費
- インフレ
- 毎月の積立
- 指定した売却
- 運用資産ごとの想定利回り

運用結果は、入力した一定の想定利回りに基づく単一の見通しです。市場変動を確率的には計算しません。

年間インフレ率と年間想定利回りは、複利で月次換算します。当月の入金は翌月から運用対象とし、当月に運用資産から出た金額は当月の運用対象から除外します。そのため、当月の積立額と売却額には当月の運用損益を付けません。

### 8. 結果表示と再計算

一つのプランについて、少なくとも以下を確認できます。

- 月ごとの生活資金口座残高
- 月ごとの総資産
- 終了年齢時点の総資産
- 最初に生活資金口座が不足する年月
- 最初に資産が枯渇する年月
- 終了年齢まで総資産を維持できたか

利用者は入力条件を変更し、同じプランを再計算できます。二つのプランの同時比較や、入力内容の保存・読込はMVPに含めません。

### 9. 現金不足と資産枯渇

生活資金口座の月末残高が0円未満の場合は、現金不足と判定します。運用資産は自動売却せず、シミュレーションを継続します。

生活資金口座のマイナス残高は0円に補正せず、累積して賄えなかった生活資金として翌月へ引き継ぎます。

現金不足と資産枯渇は別に判定します。生活資金口座が0円未満の場合は現金不足、総資産が0円以下の場合は資産枯渇とします。一度でも資産枯渇したプランは、後に総資産が回復しても「終了年齢まで総資産を維持できた」とは判定しません。

## Out of Scope for MVP

### MVP後の候補

- 課税口座、NISA、DC・iDeCo、自社株・持株会の区別
- 取得原価、売却益、売却後取得原価
- 資産区分別の概算税
- 収入に対する概算税
- 税引後使用可能額
- 引出可能年月
- 複数種類の収入を汎用的に登録する機能
- 売却不能・売却不足の詳細警告
- 現金不足や資産枯渇からの回復履歴
- 二つのプランの比較
- 商品別の詳細な比較表示
- 保存、読込、編集再開
- 一定期間だけ続く支出
- 一時支出
- 配当・分配金
- 実績管理と計画との差の確認

### 現時点で対象外

- 日単位のシミュレーション
- 日本の税制に基づく詳細な税額の自動計算
- 退職可能年齢の自動探索
- 現金不足時の運用資産の自動売却
- 確率的な運用シミュレーション
- 複数ユーザー
- 認証
- 共有

## Acceptance Criteria

MVPは、以下の条件をすべて満たしたときに完成とします。

- [ ] 生年月、シミュレーション開始年月、退職年月、終了年齢を設定できる
- [ ] 一つの生活資金口座と、一つ以上の運用資産を設定できる
- [ ] 退職前後の定期収入と基本生活費を設定できる
- [ ] 運用資産への積立予定を設定できる
- [ ] 運用資産から生活資金口座への売却予定を設定できる
- [ ] 年間想定利回りと年間インフレ率を設定できる
- [ ] 開始年月から終了年齢に達する月まで、一つのプランを月単位で計算できる
- [ ] 月ごとの生活資金口座残高と総資産を確認できる
- [ ] 最初に生活資金口座が不足する年月を確認できる
- [ ] 終了年齢まで総資産を維持できたか確認できる
- [ ] 入力条件を変更して再計算できる

## Data and Privacy

このリポジトリはPublicです。

- 実際の資産額、収入、年金見込額などの個人データはコミットしません
- サンプルとテストには架空のデータを使用します
- 認証情報や秘密情報はコミットしません
- 個人データの保存先はGitの管理対象外にします

## Disclaimer

NestPathは個人の資産形成・退職計画を検討するためのシミュレーターです。投資、税務、法律その他の専門的な助言を提供するものではありません。計算結果は入力した仮定に基づく概算であり、将来の成果を保証しません。
